# 第一部分　主论文：量子癌症

## QUBO-Fusion：基于QUBO优化的基因选择 与RSF-BP-Cox融合模型的多癌种预后生物标志物发现方法

## 摘要

预后生物标志物的发现对于肿瘤精准治疗至关重要，然而现有方法在多队列验证中的可重复性不足。本文提出QUBO-Fusion框架，将二次无约束二值优化（Quadratic Unconstrained Binary Optimization, QUBO）模型应用于基因选择，并结合随机生存森林（RSF）与反向传播-Cox回归（BP-Cox）的加权融合策略，构建跨癌种生存风险预测模型。基于SurvivalML平台的6个癌种数据集（BRCA、CRC、LUAD、GBM、LUSC、DLBC，共14,781例样本），我们进行了系统性验证。

本研究以同癌种跨数据集验证为主结果：采用同癌种内队列间成对外部验证（pairwise cross-cohort transfer）协议：对每个癌种内的任意两个数据集（cohort A、cohort B），分别以A训练B测试，共覆盖6个癌种、43个数据集、155个无向队列对（每对双向训练测试，合计310个有向迁移），结果表明LUAD（中位C-index≈0.60）和BRCA（中位C-index≈0.58）的预后信号具有较好的跨批次可迁移性，而DLBC、LUSC的跨数据集稳健性有限（C-index接近0.50），揭示了批次效应对不同癌种的差异性影响。在此基础上进一步发现：（1）QUBO仅用约20个基因即可在跨数据集验证中达到与约500基因FullModel相近的分布水平，以约4%的基因数量实现FullModel的主体性能，体现了显著的特征精简优势；（2）同分布上界实验（7:3随机划分，作为方法潜力参照）显示，在24种基因选择-预测模型组合中，含QUBO的组合在5/6癌种上取得最优C-index，BRCA最突出（QUBO_NoRed-Fusion，0.682, p=3.12×10⁻⁸, HR=2.412），且所选基因集合内部冗余性平均降低约50%（范围45%~60%）；（3）跨癌种迁移实验揭示预后基因高度癌种特异（Jaccard相似度均值≈0.009），迁移C-index多降至0.5附近，印证了癌种定制化基因选择策略的必要性。本研究为基于量子计算启发方法的肿瘤预后建模提供了新的范式。

**关键词：QUBO基因选择；随机生存森林；深度学习Cox回归；模型融合；肿瘤预后；生物标志物发现；SurvivalML**

## 一、引言

癌症是全球范围内导致死亡的主要原因之一。据世界卫生组织统计，2022年全球新增癌症病例约2000万例，死亡约970万例。精准肿瘤学的核心目标是根据个体患者的分子特征制定个性化治疗方案，而准确的预后预测是实现这一目标的关键基础。随着高通量测序技术的快速发展，TCGA等大型基因组数据库为系统性研究癌症分子机制提供了前所未有的数据资源。然而，基因表达数据的高维特性（通常包含20,000+基因）给预后模型的构建带来了严峻挑战——如何从海量基因中筛选出真正具有预后价值的生物标志物，是当前研究的核心问题。

传统的基因选择方法主要依赖单变量Cox回归分析，通过计算每个基因与生存时间的关联强度进行排序。这种方法虽然直观，但存在两个根本性缺陷：其一，它忽略了基因间的相互作用和协同效应；其二，选出的基因集合往往存在高度冗余，即多个基因反映相似的生物学信号。近年来，基于机器学习的特征选择方法（如LASSO、Elastic Net）在一定程度上缓解了这些问题，但在处理大规模基因组数据时仍面临计算效率和泛化能力的挑战。

量子计算作为一种新兴的计算范式，为组合优化问题提供了新的求解思路。二次无约束二值优化（Quadratic Unconstrained Binary Optimization, QUBO）是量子退火的标准问题形式，它将优化目标表示为二次函数，天然适合处理带有交互项的特征选择问题。需要指出的是，本研究采用经典模拟退火算法求解QUBO问题，未使用量子硬件，重点在于QUBO组合优化框架本身的方法学价值。QUBO模型可以将基因选择问题形式化为一个统一的优化目标，同时考虑预后相关性、基因冗余性和选择基数约束。然而，将QUBO框架系统性地应用于基因选择并在多癌种上验证其有效性的研究仍然有限。

在生存预测模型方面，传统的Cox比例风险模型假设风险函数与协变量之间存在线性关系，难以捕捉基因表达数据中的复杂非线性模式。随机生存森林（RSF）通过集成多棵生存树能够自动建模非线性效应和高阶交互，但对特征的局部敏感性较高。深度学习Cox模型（如BP-Cox）利用神经网络的表示学习能力提取高阶特征，但训练不稳定且容易过拟合。单一模型往往难以在所有癌种上表现最优。

本文的主要贡献包括以下四个方面：

（1）提出基于QUBO的基因选择方法，通过构建融合单变量Cox综合评分与基因间相关性惩罚的QUBO矩阵，实现兼顾预测能力与信息多样性的基因子集优化选择；

（2）设计RSF-BP-Cox加权融合策略，通过自适应权重学习整合两种互补的生存预测模型，在保持模型稳定性的同时提升预测精度；

（3）在6个癌种数据集（共14,781例样本）上进行系统性跨癌种验证，深入分析QUBO基因选择的生物学特性、融合模型的优势以及预后基因的癌种特异性。

（4）通过跨癌种迁移、同癌种跨数据集稳健性和特征精简三项扩展验证，系统评估了QUBO预后基因的泛化边界与降维价值。

我们设计了两种QUBO基因选择变体，它们使用不同的QUBO矩阵参数：

• QUBO_Full：在QUBO矩阵中同时包含预后相关性项和冗余惩罚项（w_red = 0.35），选出20个兼顾预测能力与信息多样性的基因；

• QUBO_NoRedundancy（QUBO_NoRed）：在QUBO矩阵中仅保留预后相关性项和基数约束项，不施加冗余惩罚（w_red = 0.0），选出20个以预后信号强度为主要标准的基因。

### （二）RSF随机生存森林

随机生存森林（Random Survival Forest, RSF）是随机森林在生存分析领域的扩展。RSF通过集成大量生存树来估计累积风险函数，每棵树基于自助采样（bootstrap）构建，并在每个节点分裂时随机选择候选特征子集。

RSF的核心优势在于：（1）无需假设比例风险条件，能够自动建模非线性效应和高阶交互；（2）对高维数据具有良好的鲁棒性；（3）通过集成学习降低方差，提高泛化能力。在本研究中，我们使用超参数网格搜索确定最优树数量（80/120/150棵）和最大深度（8/10/None），最小叶节点样本数为5或8。最终预测为所有树的集成累积风险函数的加权平均。

## 三、实验设置

数据来源于SurvivalML平台，包含6个癌种类型的多队列转录组和临床生存数据。所有数据以cohort为单位进行Z-score标准化后合并。生存终点统一为总生存期（OS）。本研究设置两类实验协议：（1）同癌种跨数据集验证（主结果）采用同癌种内队列间成对外部验证协议，对每个癌种内任意两个队列（cohort A、cohort B），双向训练与测试（A→B 和 B→A），模拟存在批次效应的跨队列外部验证场景（受计算资源限制采用快速参数配置）；（2）同分布上界实验按7:3比例随机划分训练集和测试集（随机种子固定为42），作为方法潜力的上界参照。两类协议因参数配置和数据划分方式不同，结果不完全可比，需分开解读。

## 四、结果与分析

本节沿以下逻辑主线展开：首先以同癌种跨数据集验证（同癌种内队列间成对外部验证）作为主要结果，评估模型在真实批次效应条件下的泛化能力；其次以同分布上界（7:3随机划分）作为方法潜力参照；再次通过QUBO预筛与FullModel对比评估特征精简的代价与收益；最后通过跨癌种迁移验证预后基因的癌种特异性。需要说明的是：同分布结果因训练集与测试集来自同一批次，会高估实际临床性能；跨数据集验证因受计算资源限制采用快速参数配置，与同分布实验不完全可比，但更贴近外部验证的真实场景，是本研究的核心评估依据。

### （一）同癌种跨数据集验证（主结果）

为评估QUBO基因选择在可能存在批次效应的数据间的稳健性，我们进行了同癌种内跨数据集验证：利用同一癌种的不同数据集（cohort），在数据集A上训练模型，在数据集B上测试预后意义。实验覆盖6个癌种、43个数据集，共155个无向队列对（每对双向运行，合计310个有向迁移）。

值得注意的是，QUBO在不同数据集上选出的基因集合几乎完全不重叠。在155对数据集组合中，144对（93%）的QUBO选择基因零重叠，全部43个数据集的基因并集达827个（理论最大860个），去重率仅3.8%。这一现象揭示了QUBO组合优化对输入数据分布的高度敏感性——不同数据集的协方差结构和单变量Cox排序不同，导致QUBO求解器收敛到完全不同的局部最优解。

【注】本文涉及两种QUBO变体：QUBO_Full（含冗余惩罚）和QUBO_NoRed（不含冗余惩罚）。在同分布上界实验中，QUBO_NoRed在多数癌种上略优于QUBO_Full（详见第三节表2及后续讨论），原因在于冗余惩罚虽然有效降低了基因间相关性，但可能过滤掉部分对预测有边际贡献的共线性基因。本节跨数据集验证使用QUBO_Full作为默认变体。

## 五、讨论

本研究系统性地验证了QUBO-Fusion框架在六个癌种数据集上的预后预测能力，揭示了若干值得关注的发现。

首先，QUBO基因选择方法的核心创新在于将基因选择问题转化为组合优化问题，通过QUBO矩阵同时编码预测能力和冗余惩罚两个目标。实验结果表明，QUBO选择的基因集合在内部冗余性上显著优于随机选择（平均降低~50%（范围45%~60%））。在所有模型-特征集组合的全局比较中，基于QUBO基因选择的最优模型在5/6癌种上取得最高C-index，证实了QUBO特征选择的有效性。然而，值得注意的是，QUBO与TopCox方法的差距在部分癌种上较小（如BRCA和LUAD上两者持平），表明QUBO的冗余惩罚虽然有效降低了基因间相关性，但对最终预测性能的提升存在边际效应。

其次，融合模型的收益具有癌种依赖性：在GBM等非线性信号强的癌种中，融合对RSF权重的偏向带来了可观的增益；而在BRCA、LUAD等线性信号较强的癌种中，融合效果与BP-Cox相当。这说明融合策略能够灵活适配不同癌种的数据特征，但增益幅度因癌种而异。融合模型通过自适应权重学习，在不同癌种上自动调整两个基础模型的贡献比例。例如，BRCA倾向于更高的BP-Cox权重（0.70），可能因为该癌种的线性预后信号较强，BP-Cox的Cox回归框架更适合捕获此类信号；而GBM倾向于更高的RSF权重（0.80），可能因为该癌种的非线性交互效应更为复杂。这种自适应机制使融合框架能够灵活适配不同癌种的数据特征。

第三，预后基因的高度癌种特异性（Jaccard均值 ≈ 0.009）是一个重要的生物学发现。这表明不同癌种的分子预后机制存在本质差异，支持了精准肿瘤学中癌种定制化策略的理论基础。从临床转化的角度，这意味着跨癌种的通用预后基因签名可能难以获得，而基于癌种特异性基因选择的个性化模型可能更具实用价值。

第四，LUSC在本研究中呈现多重困境：同分布上界中QUBO-Fusion表现不佳（C-index = 0.555，低于Random-Fusion的0.578），跨数据集验证中C-index接近随机水平（≈0.50），跨癌种迁移中也未展现有效迁移能力。综合来看，LUSC的预后信号本身较弱且分散（无少数强相关基因），同时批次效应较大，导致QUBO的组合优化在训练集上捕获了噪声模式而非真实生物学信号。这一案例说明QUBO方法在"弱信号+强批次效应"的癌种上存在适用性边界。分析发现QUBO在LUSC上选出的基因缺乏明确的肺癌相关生物学意义，且CV性能（0.629）远高于测试集（0.555），表明存在过拟合。这提示当预后信号较弱且分散时，QUBO的组合优化可能捕获训练集特有的噪声模式。未来工作需要引入更强的正则化或集成策略来提升框架在弱信号癌种上的鲁棒性。

本研究也存在一些局限性。首先，从生物标志物发现的角度，QUBO选出基因集具有较高的批次依赖性——同一癌种不同队列间93%的基因对零重叠，表明该方法更适合构建稳健的预后预测模型，而非锁定特定可复现的生物标志物基因。其次，QUBO求解采用的是经典模拟退火算法，虽然在当前规模（80个候选基因）下能够获得良好解，但在更大规模的特征选择问题上可能面临计算效率挑战。其次，融合权重的确定依赖于交叉验证，在样本量较小的癌种上可能存在不稳定性。第三，本研究仅使用了基因表达数据，整合多组学数据（如突变、甲基化、拷贝数变异）可能进一步提升模型性能。第四，本研究的强基线对比主要集中于Fusion预测模型下的特征选择方法比较，尚未在RSF、BP-Cox等单一模型下进行完整的强基线消融，后续可进一步扩展基线覆盖的模型维度。此外，在DLBC、LUAD、LUSC等癌种上，mRMR和RF_Importance与QUBO表现相当，表明这些癌种的预后信号可能更依赖于单变量排序而非组合优化，QUBO的增量贡献主要体现在BRCA等信号较强的癌种上。

未来研究方向包括：（1）将QUBO框架扩展到多组学特征选择；（2）引入注意力机制改进BP-Cox模型的可解释性；（3）开发针对弱信号癌种的自适应正则化策略；（4）在前瞻性临床数据上验证模型的临床应用价值。

## 六、结论

本文提出了QUBO-Fusion框架，创新性地将QUBO组合优化基因选择方法与RSF-BP-Cox融合模型相结合，用于多癌种的预后风险预测与特征选择方法研究。在六个癌种数据集（共14,781例样本）上的系统验证表明：

（1）QUBO 可选出内部相关性较低的紧凑基因集，QUBO_Full 的内部冗余性较随机选择降低约 50%。强基线比较显示，QUBO_NoRed 在 BRCA 中相对 mRMR、RF_Importance 和 TopCox 具有较明显的数值优势；在其余癌种中，其表现与强基线相当或略低，表明 QUBO 的增量贡献具有癌种依赖性。

（2）同癌种跨数据集验证（同癌种内队列间成对外部验证）是本研究的核心评估，结果显示LUAD（中位 C-index 约 0.60）和 BRCA（约 0.58）均具有一定的跨批次可迁移性，其中 BRCA 的跨队列波动较 LUAD 更大；DLBC 和 LUSC 的稳健性有限，这一结果更贴近临床转化的真实场景。在同分布上界（7:3随机划分）条件下，RSF-BP-Cox融合模型在BRCA上取得最优C-index（0.682, p=3.12×10⁻⁸, HR=2.412），作为方法潜力的上限参照。

（3）跨癌种分析揭示预后基因的高度癌种特异性（Jaccard均值 ≈ 0.009），支持了癌种定制化精准医疗策略的必要性；

（4）融合权重呈现癌种特异性——线性信号强的癌种（如BRCA）倾向于更高的BP-Cox权重，非线性信号强的癌种（如GBM）倾向于更高的RSF权重，体现了融合策略对不同癌种数据特征的自适应适配能力，其增益幅度因癌种而异。
